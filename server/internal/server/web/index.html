MAKE IT YOURS

Server settings.

Save configuration, then restart services to apply changes. Files are never moved or deleted.

Restarting disconnects device streams and active uploads, cancels metadata jobs, and clears job history. Changing state folders does not migrate devices or saves. A different web port changes the dashboard URL; update your proxy if applicable.

Dashboard access

Anonymous users have full administrative access. Device synchronization still requires an approved device token.

Access changes apply immediately and invalidate existing sessions. Passwords are stored only as salted hashes. For CLI recovery, stop the server, run romsync-core reset-password, then start it again.
